# ✨ SECURITY BOT — ALL IN ONE ✨  
### 🔥 Powered by **KRISH X STAR**

A Telegram security and moderation bot with automation features, built using **Pyrogram**.  
This repo is officially branded as **ALL ME KRISH X STAR** 💎

---

## 🚀 Features
- 🔗 Auto delete bio links  
- 🚫 Detect and remove NSFW content  
- 🎭 Filter stickers and media  
- ⚡ Flood control & auto-ban  
- 🛡️ Admin abuse detection  
- 👥 `/tagall` command with emoji support  
- 🎶 Auto-play music integration  

---

## ⚙️ Requirements
- Python 3.9+  
- Pyrogram  
- TgCrypto
